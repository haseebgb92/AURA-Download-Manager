Installation guide
  1. Download the packagePick the Linux archive or Windows ZIP above. Extract the files to a location you'll keep.
  2. Start AURAOn Linux, install the required GTK dependencies and run bash scripts/install-linux.sh. On Windows, open AURA-Download-Manager.exe from the extracted folder.
  3. Add the browser extensionUse Chrome's Load unpacked option or Firefox's temporary add-on. AURA connects through a locally registered helper; no pairing code needed.

Good to know.

Will AURA capture every browser download?

No. When enabled, auto-capture handles eligible HTTP(S) downloads. Images, common webpage assets, private browsing downloads and unsupported links stay in the browser. Files needing cookies or login state may also require the browser.

Can I download images with AURA?

Yes. Images are excluded from automatic capture, but you can right-click an image or image link and use Download with AURA.

Does AURA install updates automatically?

No. It checks official GitHub Releases and lets you decide whether to install a newer version.

Is AURA open source?

The repository is public and its source can be viewed. It currently has no general open-source license. The underlying aria2 engine is a separate GPL-licensed project.
